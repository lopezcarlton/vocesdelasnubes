# Prompts — estado de uso

**Proyecto:** Voces de las Nubes  
**Fecha:** 2026-08-31

Esta carpeta conserva prompts y herramientas de trabajo que pueden tener valor histórico o operativo, pero su presencia en el repositorio **no implica que estén activos ni que constituyan política pedagógica**.

## Generador de corpus v7

`generadordecorpusv7` se conserva como antecedente experimental.

**Estado actual:** `HISTORICAL_EXPERIMENTAL_NOT_ACTIVE_FOR_COR002_PILOT`

No debe utilizarse como especificación vigente de COR002 porque contiene restricciones y definiciones desarrolladas antes del checkpoint metodológico del piloto principiante, entre ellas:

- mínimo rígido de longitud;
- tratamiento de G1–G5/P1–P5 como clasificación obligatoria previa a la escena;
- reglas de activación y cobertura que fueron posteriormente revisadas;
- obligaciones de arco y generación que produjeron oscilaciones entre naturalidad, adquiribilidad y coherencia.

El flujo activo se documenta en:

- `conocimiento/CORPUS.md`;
- `conocimiento/PEDAGOGIA.md`;
- `conocimiento/VALIDACION.md`;
- `conocimiento/fuentes/COR002_CHECKPOINT_METODOLOGICO_PILOTO_PRINCIPIANTES_v1.md`.

Durante el piloto actual:

> **escena → revisión contextual → corrección → análisis G/P → hablante → aprendizaje metodológico**

No se desarrollará un nuevo generador general ni se reactivará la generación masiva antes de contar con escenas de referencia suficientemente aceptadas para calibrarlo.

## Regla general

Un prompt puede ser:

- activo;
- experimental;
- histórico;
- reemplazado;
- de uso puntual.

Ningún prompt modifica por sí mismo el Sistema de Conocimiento. Cuando exista conflicto, prevalecen los documentos canónicos y las decisiones vigentes del proyecto.
