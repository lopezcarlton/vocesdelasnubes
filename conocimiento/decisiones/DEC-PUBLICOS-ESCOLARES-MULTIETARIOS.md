# DEC-PUBLICOS-ESCOLARES-MULTIETARIOS — Voces de las Nubes debe diseñarse para públicos escolares diferenciados por edad

```yaml
id: DEC-PUBLICOS-ESCOLARES-MULTIETARIOS
titulo: "Voces de las Nubes debe diseñarse para públicos escolares diferenciados por edad"
decision: >
  Voces de las Nubes deja de considerar como público suficiente únicamente a personas
  jóvenes o adultas con transmisión intergeneracional interrumpida. El proyecto debe
  poder producir materiales adecuados para población escolar y distinguir explícitamente
  perfiles o tramos de edad cuando esas diferencias afecten contenido, situación,
  longitud, velocidad, soporte, interacción, explicación o evaluación.

  La educación secundaria técnica constituye el primer anclaje institucional prioritario
  por la relación real de Casa de las Ciencias de Oaxaca con ese nivel y con su base de
  docentes, pero no se convierte en público exclusivo. El proyecto deberá investigar
  también materiales adecuados para estudiantes más pequeños y otros públicos.

  Esta decisión adopta el requisito de segmentación; no fija todavía las bandas de edad,
  niveles escolares ni una metodología cerrada para cada segmento.
estado: vigente
fecha: 2026-09-02
responsable: Emiliano López Carlton
validadores:
  - Emiliano López Carlton
hallazgos_que_la_sustentan:
  - HALL-0009
principios_relacionados:
  - PRIN-INVESTIGACION-ABIERTA
supuestos_implicados: []
alternativas_consideradas:
  - "Mantener un único público general de aprendices iniciales"
  - "Diseñar sólo para personas con transmisión familiar interrumpida"
justificacion: >
  La reunión con Irma Pineda hizo visible una laguna estructural: un proyecto destinado a
  tener impacto a través del magisterio y de Casa de las Ciencias necesita saber para qué
  estudiantes diseña cada material. La base institucional más inmediata está en educación
  secundaria técnica, pero limitar el proyecto a ese nivel perdería la posibilidad de
  intervenir antes en la trayectoria escolar.
impacta_a:

  - "No asumir que una adaptación por edad equivale automáticamente a una adaptación por competencia lingüística."
```
