# Fuentes

Esta carpeta contiene las fuentes formales (primarias o secundarias) que sustentan hallazgos y decisiones del Sistema de Conocimiento de Voces de las Nubes.

Cada fuente formal se almacena en un archivo independiente identificado por su código estable (`SRC-*`), con el mismo formato que hallazgos y decisiones: encabezado y bloque YAML con los metadatos de la fuente.

Esta carpeta también puede contener documentos fuente en prosa (sin metadatos estructurados) que un hallazgo referencia como respaldo directo — por ejemplo, un documento de análisis o razonamiento extendido.
