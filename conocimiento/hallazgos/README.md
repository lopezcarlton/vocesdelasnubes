# Hallazgos

Esta carpeta contiene los hallazgos atómicos del Sistema de Conocimiento de Voces de las Nubes.

Cada hallazgo se almacena en un archivo independiente identificado por su código estable (`HALL-XXXX`). Los documentos temáticos pueden referenciar estos hallazgos, pero no deben duplicar su contenido como fuente primaria.
