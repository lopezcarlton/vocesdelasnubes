# Principios

Esta carpeta contiene principios pedagógicos, metodológicos, epistemológicos o de gobernanza formalizados dentro del Sistema de Conocimiento de Voces de las Nubes.

Cada principio se almacena en un archivo independiente identificado por su código estable (`PRIN-*`). Un principio expresa una regla general que orienta decisiones recurrentes y compromisos relativamente estables del proyecto.

La genealogía canónica sigue `00_ARQUITECTURA_DEL_CONOCIMIENTO.md`:

```text
PRIN -> orienta / restringe -> DEC / PROC
```

Un principio puede hacerse explícito después de que una decisión o experiencia revele la necesidad de formular una regla más general, pero **no se define por ser un derivado normativo de una decisión**. Cuando esto ocurra, su origen histórico debe documentarse sin invertir la relación de autoridad entre tipos de entidad.

Todo `PRIN` debe cumplir los campos y estados permitidos por la Arquitectura. Un archivo llamado `PRIN-*` que no cumpla el esquema no adquiere autoridad normativa por su nombre o ubicación.
