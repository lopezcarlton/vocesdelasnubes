# Aplicaciones teóricas

Esta carpeta materializa las entidades `TEO` definidas por `00_ARQUITECTURA_DEL_CONOCIMIENTO.md`.

Una aplicación teórica registra **cómo una propuesta bibliográfica se interpreta y utiliza dentro de Voces de las Nubes**. No sustituye a la fuente (`SRC`), al hallazgo bibliográfico (`HALL`) ni a una decisión vigente (`DEC`).

```text
SRC -> HALL -> TEO -> posible DEC/PRIN/PROC

TEO != SOURCE_SUMMARY
TEO != AUTOMATIC_PROJECT_POLICY
TEO != EMPIRICAL_VALIDATION
```

Cuando una lectura bibliográfica sea compatible con una decisión adoptada por otras razones, esa compatibilidad debe distinguirse de la procedencia histórica de la decisión. No se añadirá retrospectivamente una fuente como fundamento de una `DEC` si la decisión no nació realmente de ella.

Las aplicaciones teóricas permanecen revisables frente a nueva bibliografía, evidencia del proyecto y validación con aprendices o autoridades pertinentes.
